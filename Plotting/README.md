Code to generate the figure panels indicated in the file name.

Code will take as input either of the .csv files generated by the simulation code, so adjustments will have to be made to the statements importing said files.

Many of these functions assume that "MergeRepetitions.py" has been run first to generate a "VaryEsynI ... .csv" file that takes average measures over runs of a particular parameter sweep. "BurstFreq_SingleSim.py" and "BurstFreq_MergeRepetitions.py" also need to be run to generate the "NewBurstFreq ... .csv" file. 

For Figure 4, similar scripts with the "_Sparse" annotation perform the same calculations for varied externa linput instead of E_GABA.

"ReturnMaps..." code produces both movies (Supplementary Figures) and final snapshots used in Figure 3D-G, the components of which make up Figure 1A. Note that the versions in Figure 3 are partially modified to more clearly plot the end dynamics of the system.

Plotting for Figure 4 requires first performing some data processing contained in the files beginning with "Figure4DE_". The locations of the files may need to be carefully checked for your outputs, as simulations for varying E_GABA were stored in different folders during initial workflow.
